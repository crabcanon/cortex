## 2026-05-15 - Array Indexing Anti-Pattern for Sequence Generation\n**Learning:** Using array indexing on repository list methods (e.g., `list_for_job(limit=1000)[-1]`) to determine maximum sequence numbers creates N+1 query-like inefficiencies by loading unnecessary records into memory.\n**Action:** Use direct SQLAlchemy aggregation queries (e.g., `select(func.coalesce(func.max(Model.field), 0))`) in repository methods for O(1) efficiency when determining sequence numbers.
