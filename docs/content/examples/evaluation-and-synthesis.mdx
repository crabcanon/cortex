## Provider notes

- Evaluation and synthesis adapters should receive model provider settings as complete slots.
- Local runtime profiles can route DeepEval to Kimi, OpenRouter, OpenAI-compatible endpoints, or other configured providers.
- Long model-backed jobs should use leases longer than expected provider latency; the current local examples use 300-second worker leases with 30-second heartbeats.
