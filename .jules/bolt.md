## 2025-05-18 - Optimize Repositories Batch Additions
**Learning:** Found an N+1 query problem during insertions of document tags, document chunks, document artifacts, and parse run attempts. Specifically, the service layer was iterating through collections of entities to add and calling the `.add()` method on repositories in a loop. This triggered a database `flush` and `refresh` for every single entity, producing N+1 overhead and decreasing performance during ingest.
**Action:** Created `add_many()` methods on `DocumentTagRepository`, `DocumentChunkRepository`, `DocumentArtifactRepository`, and `ParseRunAttemptRepository` that leverage `session.add_all()` to insert models more efficiently without triggering per-record `session.refresh()` queries. Updated the calling code in `cortex_parse/service.py` to collect the entities in a list and dispatch them efficiently with `add_many()`.
