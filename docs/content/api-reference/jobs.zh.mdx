Jobs 被 Parse、Knowledge、Evaluation、Synthesis 共享。所有域使用同一套状态、事件和取消契约。下面的片段是 AI 生成的 Python、JavaScript 和 Java 客户端示例。

| 方法 | 路径 | Scope | 作用 |
| --- | --- | --- | --- |
| `GET` | `/v1/jobs/{jobId}` | `jobs:read` | 获取当前状态、时间戳、进度和结果指针。 |
| `GET` | `/v1/jobs/{jobId}/events` | `jobs:read` | 读取有序 job events，用于调试或 UI timeline。 |
| `POST` | `/v1/jobs/{jobId}/cancel` | `jobs:cancel` | 请求取消排队或运行中的 job。 |
