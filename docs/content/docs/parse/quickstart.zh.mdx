这个快速上手从本地 Docker 开始，然后完整调用 Parse。下面的 API 片段是 AI 生成的 Python、JavaScript 和 Java 客户端示例。

## 1. 启动 Cortex

```bash
cd /path/to/cortex
test -f .env || cp .env.local.example .env

docker compose --env-file .env -p cortex-local -f compose.local.yaml \
  --profile docling \
  --profile eval-runtime \
  --profile synthesis-runtime \
  up -d --build
```

打开 Swagger：`http://127.0.0.1:8080/docs`。
