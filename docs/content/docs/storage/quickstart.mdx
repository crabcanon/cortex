This quickstart uses the token from the Parse quickstart. If you do not have one yet, create it with `POST /v1/dev/auth/token`. API snippets are AI-generated client examples for Python, JavaScript, and Java.

## 1. Create a sample file

```bash
cat > cortex-storage-quickstart.md <<'EOF'

This file was uploaded through Cortex.
EOF
```
