This quickstart starts with local Docker, then calls Parse end to end. API snippets are AI-generated client examples for Python, JavaScript, and Java.

## 1. Start Cortex

```bash
cd /path/to/cortex
test -f .env || cp .env.local.example .env

docker compose --env-file .env -p cortex-local -f compose.local.yaml \
  --profile docling \
  --profile eval-runtime \
  --profile synthesis-runtime \
  up -d --build
```

Open Swagger at `http://127.0.0.1:8080/docs`.
