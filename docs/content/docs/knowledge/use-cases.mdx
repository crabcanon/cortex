title: Knowledge Use Cases
description: Apply Cortex Knowledge to RAG, graph search, memory, provenance, and dataset operations.

## Product documentation RAG

Parse docs pages into Markdown, upload artifacts to Storage, ingest them into a dataset, run Cognify, and answer questions with provenance and graph paths.

## Enterprise policy assistant

Use metadata fields for jurisdiction, policy type, department, and effective date. Search can then filter policy context before the model writes an answer.

## Graph-aware financial research

The TensorZero example ingests macroeconomic and financial URLs, groups context by parser engine, and searches Knowledge to compare risks across sources.

## Agent memory

Use Memify pipelines for session persistence, triplet embeddings, or coding-rule enrichment. Store session ids and node names in metadata so agents can retrieve durable memory.

## Knowledge quality loops

Feed Knowledge Search contexts into Evaluation. If RAG faithfulness or contextual recall is low, adjust parse engine, node sets, chunking, or graph prompt profile.
