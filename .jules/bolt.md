## YYYY-MM-DD - [Optimize bulk database inserts]
**Learning:** During parsing, the application saves document tags, chunks, artifacts, and parse run attempts individually using the `add()` repository method inside `for` loops. The `add()` method calls `session.flush()` and `session.refresh(model)` for each record individually. This pattern creates unnecessary N+1 queries during bulk insertions. The solution is to introduce `add_many()` methods that leverage `session.add_all()` to insert records in bulk efficiently without triggering per-record `session.refresh()`.
**Action:** Use `add_many()` repository methods (e.g., in `DocumentTagRepository`, `DocumentChunkRepository`, `DocumentArtifactRepository`, `ParseRunAttemptRepository`) which leverage `session.add_all()` during bulk insertions. Ensure the upstream service layer (e.g., `packages/parse/src/cortex_parse/service.py`) calls these new methods.
