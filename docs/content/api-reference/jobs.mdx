Jobs are shared by Parse, Knowledge, Evaluation, and Synthesis. Use the same status, event, and cancellation contract across domains. The snippets below are AI-generated client examples for Python, JavaScript, and Java.

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `GET` | `/v1/jobs/{jobId}` | `jobs:read` | Get current status, timestamps, progress, and result pointers. |
| `GET` | `/v1/jobs/{jobId}/events` | `jobs:read` | Read ordered job events for debugging or UI timelines. |
| `POST` | `/v1/jobs/{jobId}/cancel` | `jobs:cancel` | Request cancellation for queued or running jobs. |
