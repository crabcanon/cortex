This page summarizes the current Cortex API surface from the OpenAPI spec. Detailed schemas are available in the Swagger/OpenAPI renderer; the snippets here are AI-generated Python, JavaScript, and Java API calls.

## Health and observability

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/v1/health/live` | Unauthenticated liveness probe. |
| `GET` | `/v1/health/ready` | Dependency readiness probe requiring `health:read`. |
| `GET` | `/metrics` | Prometheus scrape endpoint. |
